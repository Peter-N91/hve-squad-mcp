- **Cowork can now manage a durable HVE project in a user-selected OneDrive or
  SharePoint folder.** The v1.29 package combines one `hve-project-manager`
  Agent Skill with the dynamically discovered MCP connector. The skill creates
  or resumes a versioned project manifest, threads accepted artifacts between
  HVE stages, materializes results through Cowork's native file capabilities,
  and checkpoints each HVE-managed interaction without duplicating the server's
  live tool schemas.
