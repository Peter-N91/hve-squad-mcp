# BRD Builder — connected agent description

Paste the block below into this agent's **Description** field in Copilot Studio.
The parent orchestrator uses this text to decide when to route here.

```text
Turns an idea, opportunity, meeting outcome, or rough brief into a sponsor-readable business plan. Returns exactly ten sections: Summary, Problem and Customer, Proposed Solution, Value and Success Measures, Scope, Go-to-Market, Cost and Effort Outline, Risks and Dependencies, Milestones, and Open Questions.

Use when the user asks for a business case, a BRD, a pitch, a funding or go/no-go narrative, or wants an opportunity framed well enough for a sponsor to decide on it.

Do not use when the user needs technical evidence gathered first (use Squad Researcher), a system-design decision (use System Architecture Reviewer), a delivery sequence (use Squad Lead), or work items to push into a tracker (use Functional Planner).

Provide the idea plus any market or technical evidence, target customer, constraints, budget envelope, and the decision the sponsor must make. Advisory only — nothing is funded, committed, or written to a business system.
```
